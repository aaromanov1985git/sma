# Система сверки путевых листов

Веб-приложение для сравнения данных путевых листов из 1С с данными, предоставленными заказчиком через Excel-файлы.

## 🚀 Особенности

- ✅ **Автоматическое сравнение данных** - сопоставление по 4 компонентам (время в работе, пробег, моточасы, дежурство)
- 📊 **Детальная аналитика** - статистика по совпадениям, отклонениям и отсутствующим данным
- 🔍 **Мощные фильтры** - поиск по дате, ТС (гос. номер, гаражный номер), водителю
- 🗂️ **Сортировка** - сортировка по любому столбцу таблицы
- 📄 **Пагинация** - удобная навигация по большим объемам данных
- 💾 **Автосохранение** - данные автоматически сохраняются в localStorage
- 📥 **Экспорт** - выгрузка результатов сверки в Excel
- 🎨 **Современный UI** - адаптивный дизайн с использованием Tailwind CSS
- ⚡ **Высокая производительность** - оптимизация с помощью мемоизации и debounce

## 📋 Требования

- Node.js 18+ 
- npm или yarn

## 🛠️ Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd sma
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер разработки:
```bash
npm run dev
```

4. Откройте браузер по адресу `http://localhost:3000`

## 📦 Сборка для продакшена

```bash
npm run build
```

Результат сборки будет в папке `dist/`

## 🧪 Предпросмотр продакшен-сборки


## 📖 Использование

### 1. Основные данные документа

Заполните основные поля документа:
- Дата
- Организация (ваша компания)
- Период
- Контрагент (подрядчик)
- Номер договора

### 2. Загрузка данных заказчика

Нажмите кнопку **"Выбрать файл"** и загрузите Excel-файл с данными заказчика.

**Требования к файлу:**
- Формат: `.xlsx` или `.xls`
- Обязательные колонки:
  - № ПЛ
  - Дата ПЛ
  - Марка, модель
  - Гос. №
  - Часы, мч
  - Пробег, км
  - Моточасы, мтч
  - Простой с водителем, мч

### 3. Просмотр и фильтрация

После загрузки данные автоматически сравниваются. Используйте фильтры:
- **Все** - показать все записи
- **Сходятся** - показать только совпадающие данные
- **Отклонения** - показать только записи с расхождениями

Дополнительные фильтры:
- По дате
- По ТС (гос. номер или гаражный номер)
- По водителю (принявшему ПЛ)

### 4. Детальный просмотр

Кликните на любую строку таблицы для просмотра детальной информации:
- Сравнение ваших данных и данных заказчика
- Визуализация отклонений
- Мини-карта с треком (в разработке)

### 5. Принятие решений

Для каждого путевого листа вы можете:
- ✅ **Принять** - подтвердить объемы
- ❌ **Отклонить** - не согласиться с данными
- Использовать **"Принять все"** или **"Отклонить все"** для массовых операций

### 6. Экспорт результатов

Нажмите **"Экспорт в Excel"** для выгрузки результатов сверки с информацией о статусе каждого ПЛ.

- **Zustand 4** - управление состоянием
- **XLSX** - работа с Excel файлами
- **Lucide React** - иконки
- **React Hot Toast** - уведомления
- **date-fns** - работа с датами
